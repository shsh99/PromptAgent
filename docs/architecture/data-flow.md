# 데이터 흐름

## 목적

생성 요청, 검색, 저장과 외부 호출의 처리 순서를 정의한다.

## 적용 범위

상세 생성기, 인텐트 추출, RAG, 웹 검색, 관측성 구현에 적용한다.

- [공통 프롬프트 계약](../product/prompt-contract.md)

## 상세 생성 흐름

1. 입력 크기와 형식을 검증하고 규칙 기반 인텐트를 계산한다.
2. 모호한 입력은 LLM 구조화 추출을 수행하며 실패 시 규칙 결과로 폴백한다.
3. 프롬프트 계약의 누락 항목을 질문으로 변환하고 답변을 세션에 병합한다.
4. 내부 하이브리드 RAG와 필요한 경우 TTL 기반 웹 검색을 수행한다.
5. 시스템 정책, 인텐트, 검색 컨텍스트, 템플릿, 사용자 입력, 출력 스키마 순으로 조립한다.
6. 계약 검증과 품질 평가 후 결과·가정·출처를 반환한다.

## 저장과 추적

PostgreSQL에는 템플릿 버전, 세션, 피드백, 검색 메타데이터를 저장한다. pgvector에는 승인된 내부 문서 청크만 저장한다. 웹 본문은 장기 지식으로 자동 편입하지 않는다. 로그에는 `traceId`, 지연, 토큰·비용, 폴백 여부를 남기되 원문과 비밀값은 남기지 않는다.
