# 코드 크기 제한

## 목적

검토 가능성과 단일 책임을 유지하기 위한 분리 신호를 정의한다.

## 적용 범위

신규·수정 코드와 테스트에 적용한다. 생성 코드와 마이그레이션 데이터는 별도 관리한다.

## 함께 갱신할 문서

- [Java](java.md)
- [React·TypeScript](react-typescript.md)
- [파일·폴더 구조](file-folder-structure.md)

## 기본 한도

| 대상 | 최대 줄 수 |
| --- | ---: |
| Java 클래스 | 300 |
| React 컴포넌트 | 250 |
| 훅·서비스·유틸 파일 | 200 |
| 함수·메서드 | 50 |
| 테스트 파일 | 500 |

빈 줄과 주석을 포함한 물리 줄 수를 기준으로 한다. 한도에 접근하면 책임, 데이터 변환, UI 구역, 테스트 시나리오를 기준으로 먼저 분리한다. 줄 수를 줄이기 위한 압축 표현이나 의미 없는 래퍼 생성은 금지한다.

## 예외 기록

분리가 계약을 더 어렵게 만들거나 생성 코드 등 합리적 사유가 있으면 변경 문서에 아래를 기록한다.

```text
대상 파일:
현재 줄 수와 예상 증가:
예외 사유:
검토한 분리 대안:
책임자와 해소 기한:
추가 테스트·검토:
```

예외는 PR 검토 승인을 받아야 하며 영구 면제가 아니다.
