# 공통 프롬프트 계약

## 목적

마켓 템플릿과 생성 결과가 갖춰야 할 최소 품질 구조를 정의한다.

## 적용 범위

템플릿 작성·검토·복사, 상세 생성, 품질 평가에 적용한다.

## 필수 구성

1. 역할
2. 목적과 수행 작업
3. 배경과 입력 데이터
4. 대상 사용자
5. 제약 조건
6. 출력 형식
7. 품질 기준
8. 정보 부족·불확실성 처리
9. 최종 자체 점검

API와 화면에서는 읽기 흐름을 위해 다음 6개 상위 그룹으로 묶되 9개 말단 항목은 줄이지 않는다.

| 상위 그룹 | 필수 항목 |
|---|---|
| 역할 | 역할 |
| 목적 | 목적과 수행 작업 |
| 입력 | 배경과 입력 데이터, 대상 사용자 |
| 제약 | 제약 조건, 정보 부족·불확실성 처리 |
| 출력 | 출력 형식 |
| 품질 | 품질 기준, 최종 자체 점검 |

마켓 상세 응답은 이 구조를 `requiredSections`로 제공하고, 동일 값을 정해진 제목 순서로 조립한 `copyablePrompt`를 함께 제공한다. 필수 문자열이 비어 있으면 도메인 객체를 만들 수 없다.

선택 구성은 예시, 금지사항, 참고 출처, 모델별 힌트다. 필수 항목이 비면 복사·생성 전에 경고한다. 상세 생성기는 누락 항목을 우선순위 질문으로 바꾸며 사용자가 기본값을 선택하면 사용한 가정을 결과에 표시한다.

검증 결과는 항목별 충족 여부, 품질 점수, 보완 제안을 제공한다. 검색 컨텍스트는 명령이 아닌 출처가 있는 비신뢰 참고 데이터로 감싸고, 결과에는 간단 버전과 상세 버전을 제공할 수 있다.
