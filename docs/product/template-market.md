# 프롬프트 마켓

## 목적

업무별 검증 템플릿을 빠르게 발견하고 안전하게 복사하는 제품 계약을 정의한다.

## 적용 범위

마켓 탐색, 템플릿 상세·버전, 복사 이벤트와 게시 관리에 적용한다.

## 사용자 흐름

사용자는 카테고리·검색어·태그로 템플릿을 찾고 카드에서 목적, 대상 모델, 난이도, 검증 상태를 확인한다. 즉시 복사하거나 상세 생성기로 확장한다. 변수형 템플릿은 입력값, 필수 여부, 예시를 복사 전에 표시한다.

초기 카테고리는 업무 메일, 유튜브 기획·편집, 웹사이트 개발, 코드 오류 분석·수정, 보고서, 이미지 생성, 데이터 분석, 회의·기획이다.

## 데이터와 상태

템플릿은 변경 불가능한 버전, 작성자, 카테고리·태그, 대상 모델, 검증 결과를 가진다. 상태는 `DRAFT`, `REVIEWED`, `PUBLISHED`, `ARCHIVED`다. 게시된 버전만 기본 검색과 복사 대상이며 수정은 새 버전을 만든다.

복사 이벤트는 템플릿·버전·시각을 기록하되 불필요한 사용자 원문은 저장하지 않는다. 리뷰와 게시 권한은 분리하고 철회된 템플릿의 기존 사용 이력을 보존한다.
