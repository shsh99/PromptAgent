# AI 자동 리뷰 운영

## 목적

AI 리뷰의 권한, 출력 계약과 사람 검토 경계를 정의한다.

## 적용 범위

PR diff 자동 검토, 리뷰 프롬프트, 결과 게시와 장애 대응에 적용한다.

## 함께 갱신할 문서

- [GitHub Actions](github-actions.md)
- [Git 작업 흐름](../conventions/git-workflow.md)
- [운영 런북](runbook.md)

## 실행 모델

공식 `openai/codex-action@v1` 리뷰 job은 `contents: read`와 읽기 전용 sandbox로 diff만 분석한다. 별도 게시 job만 `pull-requests: write` 권한을 가져 결과를 댓글로 남긴다. `OPENAI_API_KEY`가 없는 포크 PR은 실패시키지 않고 안전하게 건너뛴다.

리뷰는 한글로 심각도, 파일과 줄, 근거, 재현 또는 영향, 구체적 수정안, 신뢰도를 출력한다. 보안, 데이터 손실, 계약 파괴, 테스트 누락을 우선하며 취향 차이는 차단 사유로 만들지 않는다.

## 한계와 대응

AI 리뷰는 사람 승인, 보안 검사, 테스트를 대체하지 않는다. 프롬프트와 로그에 비밀값이나 전체 사용자 데이터를 넣지 않는다. 잘못된 지적은 근거와 함께 기각하고, 유효한 지적은 테스트로 재현한 뒤 수정한다. 모델·프롬프트 변경은 변경 문서에 기록한다.
